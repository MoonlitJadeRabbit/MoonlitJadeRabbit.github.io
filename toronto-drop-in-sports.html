Personal project / Web

Toronto Drop-In Finder

A single-page site that answers one question I kept asking every week: where can I actually play badminton near me, on the day I am free, without opening six different tabs?

Built fully with AI City of Toronto open data torontodropin.ca GitHub

Overview

Toronto Drop-In Finder is a lightweight web app for browsing drop-in sports at City of Toronto community centres. Allow your browser location (or type an address if you prefer), pick a sport and a day, and the page shows nearby centres sorted by distance with session times — no account, no map maze, no digging through PDF schedules.

This project was built fully by AI. I directed the idea and requirements; the implementation itself was generated and iterated with AI tools, not hand-written line by line.

Why I built it

I play badminton casually and often try to find a session that fits between classes or commuting. Toronto has recreation information online, but it can take a while to find the right place, sport, and time.

I wanted to make this easier by building a site where people can quickly search by location, sport, and day. I used AI to help turn the idea into a working website.

If you want to try it, go to torontodropin.ca.
